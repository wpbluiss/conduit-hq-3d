## Setup (2 min)
```bash
cd conduit-hq-3d
ANTHROPIC_API_KEY=your-key-here npm run dev
```
Open http://localhost:3000 in Chrome. Click to enable mouse look.

**Controls:**
| Key | Action |
|-----|--------|
| WASD | Move |
| Mouse | Look around |
| Shift | Sprint |
| E | Interact (elevator, agents, CEO desk) |
| J | JARVIS AI assistant |
| F | Activity feed |
| ESC | Close any panel |
| Space | Unstick (teleport to spawn) |
